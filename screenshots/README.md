# Screenshots du projet

Ce dossier contient les captures d'écran du projet IT Project Manager.

## Instructions pour prendre les captures :

1. **Résolution** : 1920x1080 minimum
2. **Format** : PNG ou JPG
3. **Qualité** : Haute définition
4. **Contenu** : Interface complète avec données de démonstration

## Captures nécessaires :

- `01-login.png` - Page de connexion
- `02-admin-dashboard.png` - Tableau de bord admin
- `03-users-management.png` - Gestion des utilisateurs
- `04-projects-management.png` - Gestion des projets
- `05-tasks-management.png` - Gestion des tâches
- `06-pointage-stats.png` - Statistiques de pointage
- `07-developer-dashboard.png` - Dashboard développeur
- `08-client-view.png` - Vue client (optionnel)

## Conseils :
- Utilisez des données réalistes mais fictives
- Montrez les fonctionnalités principales
- Évitez les données personnelles réelles
